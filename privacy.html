プライバシーポリシー（fortune-shorts-tools）

制定日: 2026年11月18日

fortune-shorts-tools（以下「本ツール」）は、運営者が自分の YouTube チャンネルを管理するためだけに使う個人用ツールです。本ツールは YouTube API サービスを利用しています。このポリシーは、本ツールが Google ユーザーデータをどのように取得・利用・保存するかを説明します。Google によるデータの取り扱いは Google プライバシー ポリシーに従います。

1. 対象となる利用者

本ツールにサインインするのは運営者本人の Google アカウントだけです。運営者以外の方のデータを取得することを目的としていません。

2. アクセスする Google ユーザーデータ

本ツールが要求する権限は次の2つだけです。

  • youtube.readonly: サインインしたアカウントのチャンネルID・チャンネル名・アップロード済み動画の一覧、および本ツールが確認する動画の動画ID・タイトル・タグ・公開設定・処理状態
  • youtube.upload: 運営者が制作した動画ファイルと、そのタイトル・説明文・タグ・公開設定（非公開）・子ども向けかどうか・AI 生成コンテンツの開示を YouTube に送信するため

動画の削除、コメント、アナリティクス（再生回数など）、連絡先、Gmail、Google ドライブのファイルには、本ツールの Google OAuth 権限ではアクセスしません。

3. 利用目的

  • サインインしたアカウントのチャンネルが、登録済みのチャンネルと一致するかを確認するため（誤ったチャンネルへの投稿の防止）
  • 同じ動画を二重にアップロードしないため（アップロード済み動画の照合）
  • 動画を非公開でアップロードし、アップロード後の状態を確認するため

取得したデータを広告、販売、プロファイリングに使うことはありません。本ツールは第三者による広告やコンテンツの配信を行いません。

4. 保存するデータと保存場所

  • 認証情報（OAuth のリフレッシュトークン）: 運営者のパソコン上の専用フォルダにだけ保存します。ソースコードの保管場所（GitHub）には保存せず、ログにも出力しません。トークンは、それがどのチャンネル・用途のものかを記録した情報と結び付けて管理し、一致しない場合は使いません。
  • 二重投稿を防ぐための記録（本ツールが作るデータ）: 動画ファイルのハッシュ値、制作ID、識別用の値、アップロード時に送ったタイトルなどのメタデータを、運営者のパソコン上に保存します。これらは YouTube から受け取ったデータではありません。
  • YouTube から受け取ったデータ: アップロードした動画の動画ID、および確認のために読み取った公開設定・処理状態・タイトル・タグを、運営者のパソコン上の投稿履歴・確認記録・そのバックアップに保存します。
  • 読み直しの記録（準備済み・現在は未使用）: 保存期限の管理のために YouTube から読み直した結果（動画ID・タイトル・公開設定・処理状態と取得日時）を、運営者のパソコン上の専用の記録に保存する仕組みがあります。実際の運用では、運営者が別に承認するまで保存しません。
  • API の利用記録: 呼び出した API の種類・時刻・消費したクォータ・成否を記録します（動画の内容や YouTube から受け取ったデータは含みません）。
  • 運用記録: 運営者の作業記録を非公開の GitHub リポジトリに保存しています。YouTube から受け取ったデータ（動画IDなど）は、この記録に新たに書かない運用にしています。それ以前の記録の一部（非公開）には、アップロードした動画の動画IDが残っています。これは整理の対象として管理しており、削除のご依頼があった場合は「6. アクセスの取り消しとデータの削除」のとおり対応します。

保存期間・更新・削除: YouTube から受け取ったデータは、YouTube API サービスの開発者ポリシーに従い、保存から30日以内に YouTube から読み直して更新するか、削除します。本ツールは、保存しているデータごとに取得日時と期限（28日で警告、30日で期限）を判定する機能を備えています。期限までに読み直せない場合は、本ツールの削除機能で YouTube 由来のデータを削除します（バックアップを含みます）。本ツールが作るデータ（ハッシュ値・制作IDなど）は、同じ動画を二重にアップロードしないために必要な間だけ保存します。

5. 関係するサービスと第三者による処理

  • Google（YouTube Data API）: 上記のデータの読み取りとアップロード先です。
  • GitHub: 本ツールのソースコードと運用記録を非公開リポジトリで保管しています。このページは GitHub Pages で公開しており、GitHub はアクセスした方の IP アドレスをセキュリティのために記録します（GitHub のポリシーによる）。
  • GitHub Actions: 現在は、Google のデータや認証情報を使わないテストを手動で1回実行しただけで、本ツールの投稿処理には使っていません。投稿処理に使い始める場合は、その前にこのポリシーを更新します。
  • AI コーディング支援（Anthropic の Claude Code）: 運営者は本ツールの開発と運用の補助に AI アシスタントを使っています。その際、上記の投稿履歴・運用記録（チャンネルID・動画ID・タイトルなど）が AI アシスタントに読み込まれることがあります。認証情報は表示・送信しません。
  • Google ドライブ（パソコン版 Google ドライブ）: 完成した動画ファイルの受け渡しに、運営者自身のドライブとその同期フォルダを使います。これは本ツールの Google OAuth 権限によるアクセスではありません。

上記以外の第三者に Google ユーザーデータを提供・販売することはありません。本ツールは Cookie を使用せず、端末の情報を収集しません（このページ自体も Cookie やスクリプトを使用していません）。

6. アクセスの取り消しとデータの削除

本ツールへのアクセスは、Google のセキュリティ設定ページからいつでも取り消せます。取り消すと、本ツールは YouTube にアクセスできなくなり、処理を停止します。

運営者は、本ツールの機能で保存していた認証情報を取り消すこともできます（Google の取り消し窓口に送信し、保存していたトークンは使えない状態にします）。

保存したデータの削除を希望される場合は、下記の連絡先までご連絡ください。削除のご依頼には7日以内、Google のセキュリティ設定ページでアクセスが取り消された場合は30日以内に、本ツールが保存した YouTube 由来のデータを削除します。二重投稿を防ぐための記録（ハッシュ値・制作ID）は YouTube から受け取ったデータではないため残します。本ツールが保存したデータを削除しても、YouTube 上の動画やデータには影響しません。

削除の範囲は次のとおりです。

  • 本ツールの機能で削除するもの: 運営者のパソコン上の投稿履歴・確認記録・読み直しの記録・バックアップにある YouTube 由来のデータ（動画ID・読み取った公開設定・処理状態など）。保存していた認証情報は、Google の取り消し窓口に送信して無効にします。
  • 運営者が個別に対応するもの: 非公開の GitHub リポジトリの過去の運用記録と、AI コーディング支援の作業記録に残る写し。これらは本ツールの機能では削除できないため、運営者が手作業で削除・整理します。GitHub 上の写しを完全に消すには GitHub への依頼が必要になる場合があり、その場合は期限内に依頼を行います。
